# Industrial Catalog Parser dvt-spb.ru

## Парсер товаров из интернет-каталога https://dvt-spb.ru/ на Python

Автоматизированный инструмент для сбора информации о товарах с сайтов-каталогов и сохранения данных в удобном формате для дальнейшей обработки.

Проект демонстрирует разработку полноценного парсера: от обхода категорий и страниц каталога до формирования готовой выгрузки CSV/JSON.

---

## Возможности

✅ Сбор информации о товарах
✅ Обход категорий каталога
✅ Поддержка пагинации
✅ Извлечение названия товара
✅ Извлечение цены
✅ Сбор изображений товаров
✅ Получение описания
✅ Сбор характеристик
✅ Сохранение результатов в CSV и JSON
✅ Логирование работы
✅ Обработка ошибок соединения
✅ Повторные запросы при временных ошибках
✅ Проверка robots.txt

---

## Какие данные собираются

Для каждого товара сохраняются:

* название;
* цена;
* ссылка на товар;
* изображения;
* описание;
* технические характеристики;
* категория;
* URL категории;
* дополнительные метаданные страницы.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/tscode-git/industrial-price-parser.git
```

Перейти в папку проекта:

```bash
cd industrial-price-parser
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

---

## Запуск

Тестовый запуск с ограничением количества товаров:

```bash
python src/main.py --test 20
```

Запуск с ограничением количества страниц:

```bash
python src/main.py --max-pages 100
```

После выполнения будут созданы файлы:

```
products.csv
products.json
parser.log
```

## Особенности реализации

### Безопасный сбор данных

В проекте предусмотрены:

* ограничение частоты запросов;
* случайная задержка между обращениями;
* обработка сетевых ошибок;
* повторные попытки запроса;
* ведение журнала работы.

### Работа с каталогами

Парсер умеет:

* находить товары внутри категорий;
* переходить по страницам каталога;
* избегать повторного сбора одинаковых товаров;
* сохранять структуру категорий.
